目前的行為
⚠ 潛在問題
  • 專案名稱是全域的，不分網站
  • URL 含 query params → 同一頁面可能變成兩筆
  • 跨分頁開啟工具，會沿用上次的專案名稱
  • 無法看到一個專案裡有哪些頁面
✓ 運作良好
  • 資料立即持久化，不需手動儲存
  • 同專案、同 URL 的標註自動合併
  • 可建立多個專案做隔離
  • 可以刪除整個專案
