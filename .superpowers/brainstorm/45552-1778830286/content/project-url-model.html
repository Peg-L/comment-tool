一個專案 → 多個頁面，怎麼切換？

例如專案「sprint-1」裡同時標了 /dashboard 和 /settings

A

每個專案只綁定一個 URL

建立專案時指定一個主頁面，切換就直接跳到那頁。簡單明確，適合每次只看一個頁面。

優點

  • 操作最簡單
  • 切換即導航

缺點

  • 無法標多頁
B

專案有多頁，選專案後再選頁面

選專案 → 展開頁面清單 → 點頁面才開啟。適合需要跨多頁標註的工作流程。

優點

  • 支援多頁標註
  • 有完整的專案全貌

缺點

  • 多一層操作
C

切換專案 = 換到「這個頁面」的標註

不導航到其他頁，只是把「目前這頁」換成另一個專案的標註。URL 不變，只換標註組。

優點

  • 不離開目前頁面
  • 方便比較不同版本的標註

缺點

  • 不會跳頁，需要自己導航
