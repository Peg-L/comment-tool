這個工具要以什麼形式交付？

選擇一個最符合你使用情境的方案

A

Bookmarklet（書籤工具）

拖一個書籤到瀏覽器工具列，點擊後就能在任何網頁上啟動標註模式。無需安裝，跨瀏覽器支援。

優點

  • 零安裝，即點即用
  • 可在任何網站上使用

限制

  • 部分網站的 CSP 政策可能阻擋
  • 功能較受限
B

獨立 Web App（iframe 模式）

一個獨立的網頁應用程式，透過 iframe 或 side-by-side 預覽目標頁面並進行標註。所有標註資料存在自己的後端。

優點

  • 完全掌控資料與 UI
  • 多人共享最容易實作
  • 不受目標網站限制

限制

  • 跨域 iframe 限制（X-Frame-Options）
  • 需要獨立部署
C

Chrome Extension（仍然是最完整的）

雖然你說不一定要做成 Chrome 插件，但它能直接在真實頁面上標註，不受 iframe 跨域限制，功能最完整。

優點

  • 直接操作真實 DOM
  • 最接近 UISelector2AI 體驗

限制

  • 需要安裝，有審核流程
D

JavaScript 注入腳本（Userscript / Tampermonkey）

類似 Bookmarklet 但更持久，透過 Tampermonkey 等工具自動在目標網站注入標註工具列。

優點

  • 比 Bookmarklet 持久、功能更強
  • 無需上架審核

限制

  • 需要安裝 Tampermonkey
