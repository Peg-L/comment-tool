# 💬 審核小精靈 (Comment Tool)

一個輕量、免安裝、基於書籤小程式 (Bookmarklet) 的網頁標註工具。旨在協助設計師、PM 或審核人員在任何網頁上精確地指出修改意見，並將其轉換為開發者或 AI 易於處理的格式。

---

## 🚀 快速開始

### 1. 安裝工具
開啟本專案的 `index.html` (或部署後的安裝頁面)，將 **「v1.0.0 審核小精靈」** 按鈕拖曳到你的瀏覽器書籤列。

### 2. 開始標註
1. 前往任何你想標註的網頁。
2. 點擊書籤列中的「審核小精靈」。
3. 點擊 **「🎯 選取元素」**，然後在網頁上點擊任何 UI 元素。
4. 在彈出的對話框中輸入修改建議或審核意見。

### 3. 交接標註
*   **給 AI**：點擊 **「📋 複製 Prompt」**，系統會生成包含 URL、DOM Selector 及修改指令的內容，直接貼給 ChatGPT / Claude。
*   **給同事**：點擊 **「📦 複製資料」** 取得 JSON 內容；同事在同一網域開啟工具後，點擊 **「貼上資料」** 即可載入。

---

## ✨ 核心功能

*   **免安裝外掛**：透過書籤即可啟動，支援所有現代瀏覽器。
*   **精確定位**：自動生成強健的 CSS Selector，並在頁面上標示數字編號。
*   **多頁面管理**：一個專案內可包含同網站多個路徑的標註，透過「頁面清單」快速切換。
*   **雙模式切換**：
    *   **審核者模式**：可新增、編輯與刪除標註，完整閱讀所有意見。
    *   **開發者模式**：支援「已完成」勾選，勾選後標註會變暗並加上刪除線，協助追蹤進度。
*   **Shadow DOM 隔離**：工具 UI 完全運行在 Shadow DOM 中，不會干擾原網站的樣式，也不受原網站 CSS 影響。
*   **持久化儲存**：資料儲存於瀏覽器的 LocalStorage，關閉視窗後標註依然存在。

## 🛠️ 技術架構與邏輯

### 1. 核心模組
*   **`src/index.js`**: 應用程式進入點。負責模組間的調度 (Composition Root)、事件監聽與全域狀態管理。
*   **`src/panel.js`**: UI 元件。使用 Shadow DOM 構建側邊面板、對話框與按鈕。
*   **`src/picker.js`**: 元素選取器。處理滑鼠懸停效果、點擊攔截，並生成該元素的 Selector 與 Metadata。
*   **`src/overlay.js`**: 視覺層。在原網頁上方渲染標註編號 (Badge) 與選取框 (Outline)。
*   **`src/store.js`**: 儲存層。處理 LocalStorage 的讀寫，提供「專案」與「頁面」的邏輯層抽象。
*   **`src/exporter.js`**: 轉換層。負責將內部的標註資料轉換為 AI Prompt 或可攜式的專案 JSON。

### 2. 儲存邏輯 (Storage Model)
本工具以網域為基礎進行隔離儲存。主要的 Key 格式如下：
*   **當前專案指標**：`comment-tool:__current-project__`
*   **專案名稱清單**：`comment-tool:__project-list__`
*   **標註資料**：`comment-tool:{projectName}:{pageUrl}`

### 3. 資料結構 (Annotation Shape)
每一筆標註包含：
```json
{
  "id": "隨機 ID",
  "selector": "CSS 選擇器",
  "elementLabel": "標籤名稱或類名",
  "text": "意見內容",
  "meta": {
    "tagName": "DIV",
    "innerText": "元素內文字",
    "attrs": { "id": "...", "class": "..." }
  },
  "done": false,
  "createdAt": "ISO 時間戳記"
}
```

## 📦 開發與建置

本專案使用原生 JavaScript (ES Modules)，不依賴大型框架。

### 建置指令
將源碼打包成單一的 `dist/comment-tool.js` 以供書籤載入：
```bash
npm run generate
```

### 測試指令
使用 Vitest 進行單元測試：
```bash
npm test
```

### 開發模式
啟動本地伺服器：
```bash
npm run dev
```

## ⚠️ 注意事項

1.  **資料儲存**：資料存在您的電腦瀏覽器中。清除瀏覽器快取 (特別是 Cookie 及其他網站資料) 時，標註資料會被刪除。
2.  **安全性 (CSP)**：在某些安全性設定嚴格的網站 (如 GitHub, Google) 可能因內容安全政策 (CSP) 限制而無法載入外部腳本。
3.  **無痕模式**：在無痕視窗下，資料僅在該次工作期間有效，關閉所有無痕視窗後將被清除。
